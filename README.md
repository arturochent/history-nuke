# History Nuke

Search your Chrome history by keyword and date range, select exactly what you want gone, and delete it in one click. Everything runs locally in your browser.

[English](#english) | [Español](#español)

---

## English

### What it does

Chrome only lets you clear your history by preset time ranges: the last hour, the last day, or everything. History Nuke lets you search by keyword and date range, tick the entries you want to remove, and delete them in bulk.

It also has a dark mode that remembers your choice, and it switches between English and Spanish automatically based on your browser language.

### Install

Install it from the [Chrome Web Store](https://chromewebstore.google.com/detail/history-nuke/hkodblacmofcjjhabmdlidkpinghlega).

To run it from source instead:

1. Download or clone this repository.
2. Open `chrome://extensions` and turn on Developer mode.
3. Click "Load unpacked" and select the repository folder.

### How to use it

1. Open the popup and type the word you want to search for.
2. Adjust the date range if needed.
3. Check the entries you want to remove.
4. Click delete.

### Privacy

The extension requests two permissions, `history` and `storage`. It has no servers and sends nothing anywhere. The only thing it saves is your dark mode preference, which stays on your machine. The full policy, in English and Spanish, is here: https://arturochent.github.io/history-nuke/

## Español

### Qué hace

Chrome solo te deja borrar el historial por rangos de tiempo predefinidos: la última hora, el último día o todo. History Nuke te deja buscar por palabra clave y rango de fechas, marcar las entradas que quieres eliminar y borrarlas en masa.

También tiene modo oscuro, que recuerda tu preferencia, y cambia solo entre español e inglés según el idioma de tu navegador.

### Instalación

Instálala desde la [Chrome Web Store](https://chromewebstore.google.com/detail/history-nuke/hkodblacmofcjjhabmdlidkpinghlega).

Para ejecutarla desde el código fuente:

1. Descarga o clona este repositorio.
2. Abre `chrome://extensions` y activa el modo de desarrollador.
3. Pulsa "Cargar descomprimida" y elige la carpeta del repositorio.

### Cómo usarla

1. Abre el popup y escribe la palabra que quieres buscar.
2. Ajusta el rango de fechas si hace falta.
3. Marca las entradas que quieres eliminar.
4. Pulsa borrar.

### Privacidad

La extensión pide dos permisos, `history` y `storage`. No tiene servidores y no envía nada a ningún lado. Lo único que guarda es tu preferencia de modo oscuro, y se queda en tu equipo. La política completa, en inglés y español, está aquí: https://arturochent.github.io/history-nuke/
